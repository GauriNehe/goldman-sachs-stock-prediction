# Goldman Sachs Stock Prediction
A stock price prediction model for Goldman Sachs (GS) using Linear Regression.
## Overivew
This project predicts the next day closing price of Goldman Sachs (GS) stock using historical price data and technical indicators.

## feature used
- 7 day and 30 day moving averages
- Previous day's closing price

## Results
-  RMSE:17.22
-  R-squared score:0.98
